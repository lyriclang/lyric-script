# Changelog

What each release changed for a user of Lyric-Script. The Lyric 4.x changelog up to 4.6 is
archived at [`docs/archive/4.x/CHANGELOG.md`](docs/archive/4.x/CHANGELOG.md).

## 1.0.0 — unreleased

Lyric-Script 1.0 is a new language of the Lyric family, written in Lyric 5, not an update of
Lyric 4.x: nothing of the 4.x toolchain carries over, and 4.x programs reach it through
`lyric-script fix --from-4` (design 14). The design is [`design/v1/spec/`](design/v1/spec/).
