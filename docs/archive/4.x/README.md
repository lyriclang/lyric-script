# Lyric 4.x — archive

The documents of the Lyric 4.x line up to the 4.6 cut, kept for reference. The toolchain they
describe (C# compiler, .NET bytecode VM) is the tag
[`v4.6-final`](https://github.com/lyriclang/lyric-script/tree/v4.6-final) and the branch
`archive/4.x`; build that tag to run 4.6.

| Here | What |
|---|---|
| `Grammar.md`, `guide/` | the 4.x language |
| `Bytecode.md`, `Pack.md` | the `.lyrbc` format and the packed executable |
| `design/` | the 4.x design notes |
| `Befunde_und_Verbesserungen/` | the findings that led to 4.6 |
| `examples/` | the 4.x examples — the input of the migration to Lyric-Script (S14) |
| `STATUS.md`, `CHANGELOG.md` | the 4.x status and history |

Lyric-Script 1.0 is designed in [`design/v1/spec/`](../../../design/v1/spec/).
